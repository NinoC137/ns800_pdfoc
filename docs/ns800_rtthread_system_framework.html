RT-Thread 分层实时控制框架

面向 NS800RT7P65 的单级式多端口无刷电机驱动：RT-Thread 承载系统服务层， EPWM/ADC-DMA/ISR/PDSVM 保持硬实时快路径，NPC 三电平功率级完成双直流端口能量调度与三相电机驱动。

RT-Thread 系统服务层

线程 / 事件 / 设备框架
启动编排

ns800_app_main 创建 rttinit，按序启动 PWM、ADC 与电机应用。

低速交互

buttons 5 ms 扫描参数，oled 100 ms 刷新运行状态。

保护与遥测

motguard 处理故障事件，mottelem 消费 ringbuffer 遥测帧。

调试与通信

FinSH/MSH、UART console、CAN/CANFD 与 device IPC 承载现场调试和扩展接口。

32 帧后台缓冲

双直流端口

三相无刷电机

交流侧电压合成与直流端口功率分配在同一开关周期内完成。

硬实时功率控制快路径

20 kHz 控制 / 30 kHz PWM
EPWM 触发

EPWM1 同步触发 ADC；EPWM2 提供控制 ISR 节拍。

ADC-DMA 帧

后台最新帧锁存相电流、母线量与端口状态。

控制 ISR

ns800_motor_isr 读取采样与命令，禁止阻塞操作。

PDSVM 运算

合成交流电压，同时分配高压/低压端口功率。

PWM 生成

EPWM8-13 输出三相 upper/lower 桥臂 PWM。

能量流动

HV、LV 与电机侧无需额外 DC/DC 级即可调度功率。

RTOS 边界 RT-Thread 管理并发服务、设备抽象与调试入口，不直接替代高频控制 ISR。
快路径边界 控制 ISR、PDSVM 与 EPWM compare 更新保持固定节拍和短执行路径。
采样边界 EPWM 触发与 EDMA 搬运降低 CPU 采样负担，向控制和显示共享最新帧。
功率边界 NPC 三电平单级拓扑把直流端口能量调度与三相逆变合并在同一功率级。
