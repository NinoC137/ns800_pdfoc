系统设计流程

设计从多端口电机驱动需求出发，先建立 RT-Thread 软件分层，再接入 NS800RT7P65 的采样、控制与 PWM 硬件链路。 最终形成一条可调试、可保护、可扩展的软硬件闭环。

01 需求定义

多端口功率流控

面向高压主电池、低压辅助电池与三相无刷电机，目标是在单级功率级内完成电机驱动与端口功率分配。

02 RTOS 架构

RT-Thread 分层

rtconfig.h 启用线程、事件、互斥量、ringbuffer、FinSH/MSH、serial、CAN/CANFD、ADC、PIN 和设备框架。

03 系统服务

低速任务隔离

buttons、oled、motguard、mottelem 承载交互、显示、故障和遥测，避免进入控制 ISR。

04 调试闭环

在线验证入口

pwm_duty、adc_bg_dump、motor_status、motor_ol 支撑功率级 bring-up 与运行状态检查。

05 启动编排

按依赖启动模块

ns800_app_main 启动交互与 PWM；rttinit 再启动 ns800_adc_background_start 与 ns800_motor_app_start。

06 硬件采样

EPWM1 → ADC → EDMA

EPWM1 SOCA 触发 ADCA SOC0-SOC9，EDMA 搬运 10 路结果到 32 帧缓冲，ns800_adc_background_latest 提供最新帧。

07 实时控制

EPWM2 ISR + PDSVM

ns800_motor_isr 读取采样和命令，执行电机控制与 PDSVM，保持无打印、无动态内存、无阻塞路径。

08 功率执行

EPWM8-13 驱动 NPC

ns800_pwm_app_write_svm 将 upper/lower 三相占空比映射到 EPWM8-13，驱动三电平桥臂并完成能量调度。

软件主线

RT-Thread 负责并发组织、设备抽象、故障事件和调试接口。

硬件主线

EPWM、ADC、EDMA 与 PWM compare 形成确定性的采样和输出链路。

控制主线

PDSVM 在同一开关周期内完成交流电压合成和双直流端口功率分配。
