系统功能特性

本系统将单级式多端口功率拓扑与 RT-Thread 实时软件架构结合， 形成“功率可分配、控制可实时、系统可稳定运行”的电机驱动平台。

RT-Thread + PDSVM + NPC 三电平逆变器

双直流端口 PDSVM 功率分配 EPWM 触发 ADC-DMA 采样 RT-Thread 线程 事件 / 互斥 / 设备框架
01

功率分配能力

逆变器连接高压主电池与低压辅助电池，在满足交流负载功率需求的同时，实时调节两个直流端口的输出额度。

双端口输入 高压主电池提供主功率，低压辅助电池参与功率支撑。
PDSVM 分配 同一开关周期内完成交流电压合成与端口功率分配。
辅助端恢复 支持高压端向低压端充能，使辅助电池在功率支撑后快速恢复。
02

实时控制能力

RT-Thread 并行管理外设任务，高频采样与 PDSVM 运算保留在硬实时控制路径中，兼顾控制周期与外设响应。

硬实时快路径 EPWM 触发、ADC-DMA 采样、控制 ISR 与 PWM 更新保持固定节拍。
系统服务层 按键、OLED、shell、遥测、通信由 RT-Thread 线程调度。
响应并行化 控制运算不被低速外设阻塞，外设交互也保持连续响应。
03

系统稳定性

通过 RT-Thread 内核组件实现同步通信与优先级编排，将交互外设和保护逻辑从主功率控制层中隔离。

线程隔离 低速任务独立运行，避免进入高频控制中断。
事件保护 故障状态通过事件上报，由保护线程完成记录与停机处理。
优先级编排 控制链路优先保证实时性，降低外设阻塞导致硬件风险的可能性。
能量层收益 双直流端口可按负载需求动态分担功率，并支持端口间能量恢复。
控制层收益 高频采样、控制计算和 PWM 输出保持确定周期，提升驱动实时性。
系统层收益 调试、显示、通信和故障处理模块化运行，提升稳定性与可维护性。
